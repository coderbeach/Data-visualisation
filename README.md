# Data Visualization and Storytelling

## Objective
Analyze Superstore sales data using Power BI.

## Visualizations Created
- Sales by Category
- Profit by Region
- Sales Trend
- Sales by Segment
- KPI Cards

## Key Insights
- Technology category has highest sales.
- Consumer segment contributes most revenue.
- Some regions generate higher profits.

## Tools Used
- Power BI
- Superstore Dataset
